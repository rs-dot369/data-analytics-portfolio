# Week 1 – Excel & Data Cleaning & Analysis
Welcome to **Week 1** of my data analytics portfolio! This project focuses on fundamental data preparation, exploratory data analysis, and visualization using Microsoft Excel.

---

## 📋 Project Overview & Tasks Completed

The goal of this week's project was to clean a raw dataset, handle missing values, perform statistical calculations, and build interactive visual summaries.

1. **Data Cleaning & Preparation:**
   * Checked for duplicate rows and verified data integrity (confirmed zero duplicate records).
   * Handled missing values by identifying blank entries and replacing missing values in columns like the postal code field with appropriate placeholders (`N/A`).
2. **Pivot Tables & Regional Analysis:**
   * Created a dynamic Pivot Table to summarize total sales performance across various global regions.
3. **Statistical Analysis:**
   * Utilized Excel formulas to calculate key descriptive statistics for transaction sales data:
     * **Mean (Average Sale):** $246.49
     * **Median Sale:** $85.05
     * **Mode:** $12.96
4. **Conditional Formatting:**
   * Implemented conditional formatting rules to highlight top-performing transaction values within the dataset.
5. **Data Visualization:**
   * Designed professional charts to present insights clearly, including:
     * **Region-Wise Sales Bar Chart**
     * **Category-Wise Revenue Column Chart**

---

## 📊 Key Results & Insights

* **Top Performing Region:** **Western Europe** generated the highest total revenue ($1,731,929.67), followed closely by **Central America** ($1,223,100.63) and **Oceania** ($1,100,184.61).
* **Category Breakdown:** 
  * **Technology** led in total revenue at ~$4.74M.
  * **Furniture** brought in ~$4.11M.
  * **Office Supplies** generated ~$3.79M.
* **Sales Distribution:** The large gap between the average sale ($246.49) and the median sale ($85.05) indicates a right-skewed dataset, meaning a smaller number of high-value transactions are driving up the overall average.
